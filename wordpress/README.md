# Generated WordPress projection

The R&F CDS WordPress projection is generated from the parent folder's `DESIGN.md` and `css/` files.

- Source contract: `../DESIGN.md`
- Source CSS: `../css/`
- Compiler: `../scripts/compile-wordpress.mjs`
- Generated theme: `rf/`
- Operator instructions: `../WORDPRESS.md`

Do not hand-edit generated JSON or copied shared CSS. Theme-owned files inside `rf/assets/css/block-styles.css`, `rf/patterns/`, `rf/parts/`, and `rf/templates/` are maintained as the WordPress projection layer and must remain aligned with the R&F `--rf-*` contract.
